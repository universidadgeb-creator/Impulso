Tipografía

Body: 'Segoe UI','Helvetica Neue',Arial,sans-serif.

Regla de oro: Georgia (serif) solo en títulos grandes y prominentes — h1, h2, .sec-title, el logo de marca, y números/stats display grandes. Todo lo demás (h3, h4, labels, nombres de tarjeta, preguntas de FAQ) usa la fuente sans, aunque el tag sea h3/h4. Cambio pedido por Ceci: Georgia no gusta en tamaños ≤~18px.

Mantenimiento

Cómo usar esta referencia

El sitio no tiene build ni hoja de estilos compartida: cada página repite su CSS inline. Esta página documenta la fuente de verdad para que los cambios se repliquen igual en todos lados.
  • Al agregar un heading nuevo: ¿título grande de página/sección? → Georgia. ¿Label o nombre de tarjeta? → sans.
  • Al usar color: nunca hardcodear un hex — usar el token (var(--sage), etc.).
  • Al cambiar un token o primitivo: actualizarlo en los 5 archivos y reflejarlo aquí.
  • Colores de pilar/fase tienen significado fijo — no reasignar.
